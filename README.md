# StudyFlow

**StudyFlow** is a student productivity desktop application developed using Kotlin. It is designed to help students organise their college modules, manage assignments, and keep track of their academic progress.

This project is being developed as part of my second-year Software Systems Development course at South East Technological University (SETU).

## Features

StudyFlow is currently in development. Planned features include:

- **Task Management** — Create, view, update, and delete study tasks.
- **Module Management** — Organise tasks across college modules.
- **Dashboard** — View upcoming assignments and study progress.
- **Search & Filtering** — Quickly find tasks by module, priority, or status.
- **Modern GUI** — A user-friendly desktop interface with a dark theme.

## Tooling/Languages used

- **Kotlin** — Application development
- **Java Swing** — Graphical user interface
- **FlatLaf** — Modern GUI styling (planned)
- **Gradle** — Project build automation
- **JUnit 5** — Unit testing
- **GitHub Actions** — Continuous integration (planned)
